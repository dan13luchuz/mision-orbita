# Misión Órbita

Proyecto correspondiente al primer avance del curso Principios de Programación 1.

## Descripción

Misión Órbita es un simulador básico de exploración espacial desarrollado en Python. En este primer avance se implementan cuatro programas independientes relacionados con la preparación y autorización de una misión espacial.

## Estructura del proyecto

- `ejercicio1_recursos.py`: cálculo de recursos necesarios para una misión.
- `ejercicio2_combustible.py`: verificación del combustible disponible.
- `ejercicio3_soporte_tripulacion.py`: verificación de recursos para la tripulación.
- `ejercicio4_autorizacion.py`: autorización inicial del lanzamiento.

## Ejecución

1. Tener Python instalado en el equipo.
2. Abrir el repositorio en Visual Studio Code.
3. Abrir la carpeta `avance1`.
4. Seleccionar el archivo `.py` correspondiente al ejercicio que se desea ejecutar.
5. Ejecutar el programa con Python.
6. Ingresar en la terminal los datos solicitados por el programa.

Cada ejercicio se ejecuta de forma independiente.

## Convenciones y estilo

- Los nombres de las variables se escriben en `snake_case`.
- Las constantes se escriben en MAYÚSCULAS.
- Se utiliza una indentación de 4 espacios.
- Los programas utilizan únicamente la consola para entrada y salida de datos.
- Cada archivo incluye comentarios que identifican sus principales bloques lógicos.
